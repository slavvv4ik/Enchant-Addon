# Экспериментальная раскладка HUD

`hud_screen_replace.json` — попытка получить желаемую раскладку одной операцией
`replace` по `control_name`:

- сердца, броня, голод, пузыри поднимаются на 7 UI px (`-40` → `-47`);
- полоса маны стоит вплотную над полосой опыта (`offset [0, -32]`);
- цифра уровня опыта уходит влево от полосы, на её уровень (`[-107, -26]`),
  а оригинал уводится за экран по одной вертикали (`[0, -500]` — родитель
  размера `100%c`, сдвиг по X увёл бы всю группу опыта и хотбар).

**С большой вероятностью файл снова будет отклонён движком**: в v1.0.13 такие
правки привели к ошибке ресурспака, весь наш HUD пропал, а служебный заголовок
стал виден как `MM:50`. Признак той же беды — надпись `MM:…` посреди экрана.

## Как собрать

```bash
cp experimental/hud_screen_replace.json src/Mana_Machines_RP/ui/hud_screen.json
# поднять версию в src/Mana_Machines_BP/manifest.json
python3 build.py
```

Готовая сборка: `Mana_Machines_v1.0.15.mcaddon`.

Если HUD сломался — удалите паки и поставьте `Mana_Machines_v1.0.14.mcaddon`,
в нём только проверенные операции.
